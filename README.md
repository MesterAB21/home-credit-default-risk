# Home Credit Default Risk Prediction

A machine learning project developed for the **Home Credit Default Risk Kaggle competition**, predicting the probability that a loan applicant will experience payment difficulties.

## Project Overview

The project explores an end-to-end binary classification workflow using financial and applicant data to identify patterns associated with credit default risk.

- **Task:** Binary classification
- **Dataset:** Home Credit Default Risk
- **Training samples:** 307,511 loan applications in the main training table
- **Target:** Payment difficulties
- **Evaluation focus:** Classification performance on imbalanced data

## Workflow

- Explored and analyzed applicant and loan data.
- Performed feature engineering and missing-value handling.
- Encoded categorical variables and prepared preprocessing pipelines.
- Addressed class imbalance.
- Trained and compared Logistic Regression, Random Forest, Gradient Boosting, XGBoost, and neural networks.
- Evaluated model performance and generated predictions for the competition.

## Models

- Neural Networks

## Objective

Investigate how machine learning can estimate credit default risk and support more informed lending decisions, while recognizing the importance of fairness and responsible use of financial predictions.

## Dataset

[Home Credit Default Risk — Kaggle Competition](https://www.kaggle.com/competitions/home-credit-default-risk)

The main training table contains 307,511 applications, with additional files providing supplementary information about applicants and their financial histories.
